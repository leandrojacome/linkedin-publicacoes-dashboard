## Texto preparado

GitHub Actions workflow execution protections are now generally available. Teams can target rules to specific workflow files, audit impact with Insights, and manage policies through the REST API. GitHub is also rolling out a default evaluate-mode rule for pull_request_target in affected public repositories.

## Verified claims

- Workflow execution protections are generally available for GitHub Enterprise, organizations, and repositories.
- General availability adds workflow-file targeting, Insights, and REST API management.
- GitHub is rolling out a default rule for affected public repositories that initially runs in evaluate mode and limits `pull_request_target`; later enforcement is documented for November 2, 2026.

## Editorial relevance

The release gives platform and DevSecOps teams finer control over who and what can trigger sensitive workflows, plus a way to test policy impact before enforcement.
