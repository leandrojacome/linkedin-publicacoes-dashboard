Official GitHub Changelog, published September 18, 2026: https://github.blog/changelog/2026-09-18-manage-the-code-coverage-ruleset-condition-with-the-rest-api/

GitHub says the generally available REST API can now create, update, and read the existing `Restrict code coverage` repository ruleset option. The rule can enforce minimum line coverage or a maximum tolerable drop on a pull request. Previously configuration required the UI. GitHub Code Quality and code coverage uploads are prerequisites. Availability: GitHub Team and Enterprise Cloud, including data residency; not GitHub Enterprise Server. This is an API improvement, not a newly launched code coverage feature.
